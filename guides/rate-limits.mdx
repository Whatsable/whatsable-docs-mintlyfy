WhatsApp throughput and messaging caps are set by **Meta**, not by a WhatsAble plan slider. This page covers Meta **messages-per-second (MPS)** limits, the lower Coexistence MPS cap, Meta **messaging limits** outside the 24-hour customer-service window, and what WhatsAble does **not** publish as a numeric API rate (RPM).

If you need how to connect a number, start with [Connect WhatsApp (Embedded Signup + Coexistence)](/guides/whatsable/connect-whatsapp-coexistence). For plan gates and unique-contact billing, see [plans Bulk Message / Pro / Agency](/guides/notifyer-system/plans-bulk-message-pro-agency).

---

## Two different Meta limits

Do not mix these up:

| Limit type | What it controls | Who enforces it |
|------------|------------------|-----------------|
| **Throughput (MPS)** | How fast a business phone number can send/receive messages on Cloud API | Meta (per phone number) |
| **Messaging limits** | How many **unique** WhatsApp users you can message **outside** a customer-service window in a rolling 24 hours | Meta (portfolio / business capability) |

WhatsAble sits on Meta Cloud API. Hitting either limit shows up as Meta errors or undelivered business-initiated traffic — not as a WhatsAble “upgrade your RPM” control in the console.

---

## Meta throughput (messages per second)

Cite Meta’s [Throughput](https://developers.facebook.com/documentation/business-messaging/whatsapp/throughput) documentation for the live numbers. As of Meta’s published Throughput page (updated **2026-06-17**):

| Phone-number situation | Meta MPS (throughput) |
|-------------------------|------------------------|
| Default Cloud API number | Up to **80** messages per second |
| Automatic upgrade (eligibility met) | Up to **1,000** messages per second |
| **Coexistence** (WhatsApp Business app + Cloud API on the same number) | Fixed **20** messages per second |

Meta notes that throughput counts **inbound and outbound** traffic and all message types. Numbers remain subject to WhatsApp Business Account rate limits and template messaging limits even after a throughput upgrade.

**Exceeding throughput:** Meta returns Cloud API error **`130429`** (“Cloud API message throughput has been reached”) until you are back under the allowed level. Match on `code` and `error_data.details`, not on titles — see [WhatsApp Cloud API error 130429](/whatsapp-error-130429).

**Higher throughput:** Meta can auto-upgrade a number to 1,000 MPS when the portfolio has an unlimited messaging limit, the number messages enough unique users outside the service window in a rolling day, and quality is Medium (yellow) or higher. Eligibility and exact checks live on Meta’s Throughput page — WhatsAble does not sell or flip that upgrade.

## Coexistence throughput (20 MPS)

Most WhatsAble customers keep the **WhatsApp Business app** on the phone while using Cloud API (**Coexistence**). Meta fixes Coexistence numbers at **20 MPS** so the app and API stay compatible. That cap is a **Meta-side** constraint.

WhatsAble notes that match this page:

- Coexistence throughput is **Meta’s**, not a WhatsAble product limit you can raise in Settings.
- Do **not** uninstall the WhatsApp Business app after connect — that breaks Coexistence.
- Unofficial (non-Meta) API tools on that number stop once Coexistence is on.

Operator connect guide: [Connect WhatsApp Business to WhatsAble](/guides/whatsable/connect-whatsapp-coexistence). Outbound when humans type in the Business app: [Outbound WhatsApp Business app](/guides/notifyer-system/api/outbound-whatsapp-app).

## Meta messaging limits (unique recipients / day)

Separate from MPS: Meta caps how many **unique** customer numbers a business can message **outside** the customer-service window in a moving 24-hour period. Inside the window (the customer messaged you recently), free-form replies are not gated by that unique-recipient messaging-limit ladder.

Exact tier values and scaling rules change on Meta’s side. Treat [Meta Messaging Limits](https://developers.facebook.com/docs/whatsapp/messaging-limits/) and WhatsApp Manager as the live source — do not hard-code a WhatsAble “daily RPM.”

Operator notes (not a substitute for Meta’s page):

- Outside the 24-hour window, only **approved templates** start business-initiated conversations.
- Unverified Meta Business Portfolios start with a low daily unique-recipient cap; verified portfolios scale through Meta’s messaging-limit tiers up to unlimited.
- Customer replies that open or refresh the service window are not “using up” that business-initiated unique-recipient ladder the same way.

This rate-limits page only separates **messaging limits** from **MPS** so you do not mix them into one invented number.

## WhatsAble API rate limits (RPM)

**Unpublished / unknown.** WhatsAble does **not** currently publish a numeric requests-per-minute (RPM) figure for its own HTTP APIs in customer docs.

- Do **not** invent a WhatsAble RPM, “generous rate limit,” or plan-based API quota.
- Use the **Meta MPS**, **Coexistence**, and **messaging limits** sections on this page.
- If a send fails with Meta throughput details, treat it as Meta `130429` / Throughput — not as a missing WhatsAble RPM table.

## Pair rate and burst behavior (Meta)

Meta also applies **pair** rate limits when you send too many messages to the **same** WhatsApp user too quickly (separate from phone-number MPS). Meta documents this on Cloud API overview / error materials (for example throttling around error **`131056`**). Campaigns that spray many different recipients are what MPS is sized for; hammering one user is a different Meta pair limit.

WhatsAble does not override Meta pair limits.

## Operator checklist when sends slow or fail

1. **Read the error `code` and `details`.** Throughput → [130429](/whatsapp-error-130429). Do not match deprecated titles alone.
2. **Check Coexistence.** If the number still uses the WhatsApp Business app, Meta MPS is **20**, not the default 80 / 1000 ladder.
3. **Separate MPS from messaging limits.** A green throughput number can still fail business-initiated templates if Meta messaging limits / quality / cold outreach rules apply.
4. **Warm gradually on cold lists** (especially US). Meta may withhold delivery for healthy-ecosystem reasons — related codes live under WhatsAble’s Meta error pages (for example [131049](/whatsapp-error-131049)).
5. **Do not uninstall** the Business app to “raise” throughput. That breaks Coexistence; Meta’s Coexistence MPS cap remains the documented path for dual-app numbers.

## FAQ

### Does WhatsAble raise Meta’s 20 MPS Coexistence limit?

No. Coexistence MPS is fixed by Meta for app + API numbers. WhatsAble does not control or raise it.

### Where do plan unique-contact limits fit?

Those are **WhatsAble billing** (unique contacts / overage), not Meta MPS. See [plans Bulk Message / Pro / Agency](/guides/notifyer-system/plans-bulk-message-pro-agency); money stays on [pricing](https://whatsable.app/pricing).
